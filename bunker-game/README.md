# Игра "Бункер"

Веб-версия популярной карточной игры "Бункер" на выживание, реализованная с использованием Next.js и React.

## Описание игры

В игре "Бункер" участники оказываются в ситуации глобальной катастрофы. У каждого игрока есть уникальный персонаж с определенными характеристиками: профессия, возраст, состояние здоровья, хобби и другие особенности. Цель игры — убедить остальных участников, что именно ваш персонаж должен попасть в бункер и выжить.

В каждом раунде игроки представляют своих персонажей и пытаются доказать их ценность для жизни в бункере. После обсуждения проводится голосование, и один игрок выбывает из игры. Игра продолжается до тех пор, пока в бункере не останется только половина от исходного числа игроков.

## Особенности реализации

- Одиночная игра против ИИ-противников
- Генерация уникальных персонажей с различными характеристиками
- Случайная генерация типа катастрофы и характеристик бункера
- Пошаговый игровой процесс
- Система голосования для исключения игроков

## Технический стек

- Next.js (React-фреймворк)
- TypeScript
- CSS-in-JS (styled-jsx)

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone <url-репозитория>
cd bunker-game
```

2. Установить зависимости:
```bash
npm install
```
или
```bash
yarn install
```

3. Запустить проект в режиме разработки:
```bash
npm run dev
```
или
```bash
yarn dev
```

4. Открыть браузер и перейти по адресу: http://localhost:3000

## Структура проекта

- `/app` - основной каталог приложения (Next.js App Router)
  - `/components` - компоненты React
  - `/game` - страницы, связанные с игровым процессом
  - `/utils` - утилиты для генерации данных игры
- `/public` - статические файлы
